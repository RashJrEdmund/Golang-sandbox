
## EML

"Extensible Markup Language" is a text-based format for representing structured information, like JSON - but different and a bit more verbose.

```xml
  <root>
    <id>123</id>
    <name>Rash Edmund</name>
    <role>Software Developer</role>
  </root>
```

Is equivalent to

```json
  {
    "id": "123",
    "name": "Rash Edmund",
    "role": "Software Developer"
  }
```
